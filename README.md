# Site da Vitória — GitHub Pages

Envie TODOS os arquivos desta pasta para a RAIZ do repositório. Não coloque o `index.html` dentro de outra pasta.

Arquivos que devem ficar lado a lado na raiz:

- `index.html`
- `style.css`
- `script.js`
- `pool-party.png`
- `kitty-float.png`
- `kitty-swim.png`
- `kitty-party.png`
- `kitty-wave.png`
- `.nojekyll`

O `README.md` é opcional e pode ser enviado também.

Depois, no GitHub: Settings > Pages > Build and deployment > Deploy from a branch > `main` > `/(root)` > Save.

Observação: o arquivo MHT original não continha os arquivos `kitty-party.webp` e `kitty-wave.webp`. Neste pacote eles foram substituídos por cópias locais das personagens disponíveis, para que nenhuma imagem fique quebrada.
